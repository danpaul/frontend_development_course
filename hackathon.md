# Frontend Development Hackathon

## About

During weeks 1-4 in the Frontend Development course, you will develop a small hackathon project. The purpose of this project is to have a chance to practice and do some implementation work with the theory topics you are learning in class. It is important to get some practice writing code in React to prepare for the React Native portion of the class.

## Requirements

The main requirement for this project is that you _use the stack we are learning about_ in this course (React/TS/Next). You can, and probably should, start with the code in the main branch in the course code repo [https://github.com/danpaul/frontend_development_course_code](https://github.com/danpaul/frontend_development_course_code).

The other requirements is _no vibe coding_. Using agentic AI for your coding practices is however _encouraged_. See AI usage section below for more details.

Otherwise, things are pretty open and the goal is to find a fun, small project that you are excited to work on and which you think you can be completed during the course time.

You are encouraged to work in you project group for purposes of collaboration but you are allowed to work alone or in other small groups if you prefer.

## AI Usage

Using AI in a systematic and educational way is encouraged in this class. You can refer to the spec-driven development presentation to get started (`./presentations/01_spec_driven_development.html`). The last section, "SDD in practice" is the most important to get started. You don't have to follow the specific structure that is in that repo (using the exact agent skills, etc.) but it strongly recommended to use a spec-driven pattern.

It is discouraged to simply prompt your agent to complete specific tasks (prompt engineering) and it is not allowed to "vibe code" (complete large features or an entire app in one-shot).

### Educational use of AI

It is also important that you are using AI engineering in an _educational way_. You have been thrown into a fullstack application in which you are likely unfamiliar. This is a common situation for junior developers. Your goal is to use the AI agents not to simply write your code but to explain code you do not understand.

These key standards for committing code apply whether you are using AI or not:

- you are responsible for the code you commit (quality, efficiency, stability, security)
- you must understand and be able to explain every line of code you commit

_Use AI as part of your learning strategy._ Learning is an essential skill for developers (especially junior developers). A main goal with our use of AI is to develop the discipline and strategies to use AI to improve our knowledge and understanding.

## Judging

The judging for the hackathon occurs during week 4, in class. You will have 5-10 minutes to quickly demo your app and then explain a small snippet of code that you found interesting or challenging.

You will be judged based on the three criteria:

- The uniqueness and quality of the app idea
- The professional polish of the app
- The quality of the code explanation and understanding
