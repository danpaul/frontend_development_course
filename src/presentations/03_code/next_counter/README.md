This is a [Next.js](https://nextjs.org) App Router demo for the hydration lecture.

A **Server Component** (`src/app/counter/page.tsx`) passes `initialCount={10}` into a **Client Component** (`src/app/counter/Counter.tsx`). View page source to see `10` in the HTML, then click Increment to confirm the island hydrates.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000/counter](http://localhost:3000/counter).
